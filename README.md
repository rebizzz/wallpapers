# Wallpapers

A personal collection of desktop wallpapers, sorted by category.

## Categories

- **abstract** — abstract and surreal art
- **anime** — anime and illustrated art
- **fantasy** — fantasy and dark fantasy art
- **games** — screenshots and art from video games
- **nature** — photos and paintings of natural landscapes

## Usage

Each folder holds full resolution images ready to use as wallpapers. Pick whatever fits your screen and set it directly, no conversion needed.
